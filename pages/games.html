Yayın & oyunlar

Oyun ön ayarları

Her oyun için hazır, yayına uygun bir HUD düzeni: games/<oyun>/index.html. Hepsi aynı veri protokolünü konuşur — oyun tarafı yalnızca game:set ile sayıları, game:kill / game:gift gibi mesajlarla olayları gönderir. FiveM/RedM'de NUI sayfası olarak, HTML arayüzü olmayan oyunlarda (Left 4 Dead vb.) OBS tarayıcı kaynağı + WebSocket ile çalışır. Aşağıdaki önizlemeler ?demo=1 ile sahte veriyle oynuyor.

Yeni sekmede aç
Adres: · Oyunda kullanırken demo=1'i kaldır, gerekiyorsa crop=vertical&platform=tiktok ve ws=ws://127.0.0.1:8787 ekle.

Bağlama

Oyun tarafından bağlanma yolları

-- FiveM / RedM (client.lua) · mhud kaynağıyla
exports.mhud:Send('game:set', {
  hp = GetEntityHealth(ped) - 100,
  kills = kills, deaths = deaths,
  onScreen = alive, queued = #queue
})
exports.mhud:Send('game:kill', {
  actor = 'Amiral Router', victim = 'Ballas #12',
  weapon = 'carbine', headshot = true, self = true
})
// Left 4 Dead vb. — OBS tarayıcı kaynağı:
// games/l4d2/index.html?ws=ws://127.0.0.1:8787
// köprü sunucusu her satırı JSON olarak yollar:
{ "action": "game:set",
  "data": { "hp": 64, "onScreen": 18, "queued": 42 } }
{ "action": "game:infected",
  "data": { "name": "Tank", "boss": true } }
// sayfa açılınca köprüye { action: 'hello' } gönderir
<!-- Kendi HTML oyunun: düzeni iframe'e koy -->
<iframe src="mhud/games/arena/index.html"></iframe>
// ve postMessage ile besle
hud.contentWindow.postMessage({
  action: 'game:set',
  data: { score: 48250, combo: 3, lives: 2 }
}, '*')
